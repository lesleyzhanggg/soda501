"Book GOPC" mobile application function rolled out to more clinics
******************************************************************
The following is issued on behalf of the Hospital Authority:
The Hospital Authority (HA) is now rolling out the mobile application function "Book GOPC" in phases to clinics in more districts. Beginning today (August 28), members of the public can use the mobile application for appointment booking for all General Out-patient Clinics (GOPCs) in Kwai Tsing, Sham Shui Po, Tsuen Wan and Islands Districts. The HA aims to gradually roll out the "Book GOPC" mobile application function to the remaining GOPCs in the New Territories by the end of September.
Clinic staff will assist patients who need to activate their "HA Go" accounts. The GOPC Telephone Appointment System continues to provide its booking service as usual. For details of the means of booking for GOPC services and other related information, including the tentative rollout schedule of the mobile application function "Book GOPC", please visit the GOPC website (
www.ha.org.hk/gopc
).
